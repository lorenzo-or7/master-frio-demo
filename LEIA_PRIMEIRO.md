# MASTER FRIO — ARQUIVOS PARA CLAUDE CODE

Este pacote contém o prompt mestre e os assets padronizados para executar o protótipo local.

## Como usar
1. Extraia este ZIP numa pasta de trabalho vazia.
2. Abra essa pasta no Claude Code.
3. Peça para ler e executar `PROMPT_MESTRE_MASTER_FRIO_CLAUDE_CODE.md` por completo.
4. O Claude deve criar o projeto Vite e manter `public/assets/` nas mesmas rotas.
5. Este pacote leve inclui as fotografias WebP otimizadas para o site; matrizes JPG 8K opcionais foram omitidas para facilitar o download.
6. Não publicar nem fazer commit/push/deploy sem autorização.
